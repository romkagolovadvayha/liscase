# PROSTOJ support sticker set

32 static chat stickers featuring the bucket-helmet character from the supplied references.

- Format: WebP with alpha transparency
- Canvas: 512 x 512 px
- Caption font: `RobotoCondensed-Black.ttf` from `frontend/assets/fonts/Roboto_Condensed/static/`
- Caption treatment: warm off-white Rust UI-style type with a hard black offset shadow
- Artwork: original chibi illustrations with simplified Rust-inspired props

## Prompt system

All artwork was generated with the built-in image generator using the supplied character images as identity and style references. The shared prompt locked the character to a brown hair cap, steel bucket faceplate with side rivets and two black eye holes, red shirt, dark blue pants, brown shoes, thick irregular black linework, flat two-tone cel shading, and a white die-cut border. Captions were deliberately excluded from generation and added locally with the real Roboto Condensed Black font so Russian text stays exact and consistent.
