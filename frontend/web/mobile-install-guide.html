📱 Установка приложения

🤖 Android (Chrome)

1️⃣
Откройте меню браузера
Нажмите на три точки в правом верхнем углу
2️⃣
Найдите "Установить приложение"
Или "Добавить на главный экран"
3️⃣
Подтвердите установку
Нажмите "Установить" в диалоге

🍎 iOS (Safari)

1️⃣
Нажмите кнопку "Поделиться"
Это квадрат со стрелкой вверх
2️⃣
Выберите "На экран Домой"
Прокрутите вниз и найдите эту опцию
3️⃣
Нажмите "Добавить"
Приложение появится на домашнем экране

💡 Преимущества установленного приложения

  • Быстрый доступ с домашнего экрана
  • Работает как обычное приложение
  • Уведомления о новых сообщениях
  • Работает в офлайн режиме
  • Не занимает много места

Попробуйте открыть его с домашнего экрана!
