# Как посмотреть Harmony-мод (например RustDemoPro.dll)

Скомпилированный мод — это обычная .NET DLL. Исходный код из неё можно **посмотреть** только через декомпиляцию.

---

## 1. Просмотр структуры (типы и методы) без полного кода

В папке **plugins/InspectDll** лежит маленькая утилита: она загружает DLL и выводит список всех типов и методов.

**Запуск (из папки InspectDll):**
```bash
cd plugins/InspectDll
dotnet run -- "..\RustDemoPro.dll"
```

Или после сборки:
```bash
InspectDll\bin\Debug\net48\InspectDll.exe "D:\path\to\RustDemoPro.dll"
```

Так ты увидишь имена классов, методов и полей — этого часто хватает, чтобы понять, куда смотреть в декомпиляторе.

---

## 2. Полная декомпиляция (исходный C#)

Нужен декомпилятор .NET:

### dnSpy (удобно для просмотра и отладки)
- Сайт: https://github.com/dnSpyEx/dnSpy/releases  
- Скачай, установи, открой **File → Open** и выбери `RustDemoPro.dll`.  
- В дереве слева будут все пространства имён и классы, справа — декомпилированный C#.  
- Поиск: **Ctrl+Shift+K** (по строке/имени).

### ILSpy (если предпочитаешь его)
- Сайт: https://github.com/icsharpcode/ILSpy  
- Аналогично: открываешь DLL и смотришь дерево типов и код.

### ILSpy в командной строке (если установлен dotnet)
```bash
dotnet tool install --global ilspycmd
ilspycmd -p -o ./RustDemoPro_Source RustDemoPro.dll
```
После этого в папке `RustDemoPro_Source` будет проект с C#-файлами.  
(Если `dotnet tool install` падает из-за NuGet-источников — используй dnSpy/ILSpy с GUI.)

---

## 3. Где и что искать в RustDemoPro

После открытия DLL в dnSpy/ILSpy имеет смысл искать:

- По строкам: **"kill"**, **"demo"**, **"15"**, **"second"**, **"clip"**, **"highlight"** — чтобы найти логику обрезки по киллам.
- Классы с именами вроде **Demo**, **Clip**, **Highlight**, **Kill**.
- Методы **HarmonyPatch** (атрибуты `[HarmonyPatch(...)]`) — так помечаются места, куда мод «врезается» в игру.
- Вызовы, связанные с записью/сохранением демо и отправкой на сервер (сетевые запросы, файлы).

Так можно понять, как в RustDemoPro реализована вырезка «15 секунд до/после килла» и куда отправляется результат, и повторить идею у себя.

---

**Важно:** декомпилированный код можно использовать только для изучения и совместимости. Переиспользование чужого кода должно соответствовать лицензии мода и авторским правам.
