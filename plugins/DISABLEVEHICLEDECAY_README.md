# DisableVehicleDecay

Плагин для полного отключения ломания (decay) всех транспортных средств на сервере Rust.

## Описание

Плагин полностью отключает decay для всех типов транспортных средств на сервере. Поддерживает все виды транспорта: вертолеты, лодки, машины, велосипеды, снегоходы, подводные лодки, осадные орудия, воздушные шары, лошади и сани.

## Возможности

- ✅ Полное отключение decay для всех транспортных средств
- ✅ Автоматическая защита новых транспортных средств при размещении
- ✅ Индивидуальная настройка для каждого типа транспорта
- ✅ Защита существующих транспортных средств при загрузке плагина
- ✅ Команды для управления плагином
- ✅ Логирование защищенных транспортных средств
- ✅ Консольные команды для администраторов

## Поддерживаемые типы транспорта

- **Вертолеты**: Minicopter, Scrap Transport Helicopter, Attack Helicopter, Player Helicopter
- **Лодки**: Rowboat, RHIB, Tugboat, Kayak
- **Машины**: Modular Car
- **Велосипеды**: Motor Bike, Motor Bike Sidecar, Pedal Bike, Pedal Trike
- **Снегоходы**: Snowmobile, Tomaha
- **Подводные лодки**: Solo Submarine, Duo Submarine
- **Осадные орудия**: Ballista, Battering Ram, Catapult, Siege Tower
- **Воздушные шары**: Hot Air Balloon
- **Лошади**: Ridable Horse
- **Сани**: Sled, Sled Xmas

## Установка

1. Скопируйте файл `DisableVehicleDecay.cs` в папку `oxide/plugins/`
2. Плагин автоматически загрузится при следующей перезагрузке сервера или плагинов
3. Настройте конфигурацию в файле `oxide/config/DisableVehicleDecay.json`

## Конфигурация

```json
{
  "Включить плагин": true,
  "Отключить decay для вертолетов": true,
  "Отключить decay для лодок": true,
  "Отключить decay для машин": true,
  "Отключить decay для велосипедов": true,
  "Отключить decay для снегоходов": true,
  "Отключить decay для подводных лодок": true,
  "Отключить decay для осадных орудий": true,
  "Отключить decay для воздушных шаров": true,
  "Отключить decay для лошадей": true,
  "Отключить decay для саней": true,
  "Логировать защиту транспорта": true

```

### Параметры конфигурации

- **Включить плагин** - Включает/выключает плагин
- **Отключить decay для вертолетов** - Отключает decay для всех типов вертолетов
- **Отключить decay для лодок** - Отключает decay для всех типов лодок
- **Отключить decay для машин** - Отключает decay для модульных машин
- **Отключить decay для велосипедов** - Отключает decay для всех типов велосипедов
- **Отключить decay для снегоходов** - Отключает decay для снегоходов
- **Отключить decay для подводных лодок** - Отключает decay для подводных лодок
- **Отключить decay для осадных орудий** - Отключает decay для осадных орудий
- **Отключить decay для воздушных шаров** - Отключает decay для воздушных шаров
- **Отключить decay для лошадей** - Отключает decay для лошадей
- **Отключить decay для саней** - Отключает decay для саней
- **Логировать защиту транспорта** - Включает логирование в консоль сервера при защите транспортных средств

## Команды

### Игровые команды (чат)

- `/vehicledecay` - Показать справку по командам
- `/vehicledecay protect` - Защитить все транспортные средства на сервере
- `/vehicledecay count` - Показать количество транспортных средств (всего, защищено)
- `/vehicledecay enable` - Включить плагин
- `/vehicledecay disable` - Выключить плагин
- `/vehicledecay status` - Показать статус плагина и текущие настройки

### Консольные команды

- `vehicledecay.protect` - Защитить все транспортные средства на сервере
- `vehicledecay.count` - Показать статистику по транспортным средствам
- `vehicledecay.enable` - Включить плагин
- `vehicledecay.disable` - Выключить плагин

## Права доступа

Для использования игровых команд требуется право: `disablevehicledecay.admin`

Выдать право игроку:
```
oxide.grant <player> disablevehicledecay.admin
```

Выдать право группе:
```
oxide.grant group <group> disablevehicledecay.admin
```

## Примеры использования

### Базовое использование

1. Загрузите плагин - все существующие транспортные средства будут автоматически защищены
2. При размещении новых транспортных средств они будут автоматически защищены от decay

### Выборочная защита

Если вы хотите отключить decay только для определенных типов транспорта, измените конфигурацию:

```json
{
  "Включить плагин": true,
  "Отключить decay для вертолетов": true,
  "Отключить decay для лодок": false,
  "Отключить decay для машин": true,
  ...
}
```

В этом примере decay будет отключен только для вертолетов и машин, но лодки будут продолжать ломаться.

### Ручное управление

Администратор может вручную защитить все транспортные средства командой:
```
/vehicledecay protect
```

Проверить количество транспортных средств:
```
/vehicledecay count
```

## Логирование

При включенном логировании в консоли сервера будут отображаться сообщения вида:

```
[DisableVehicleDecay] Защищено транспортных средств: 15
[DisableVehicleDecay] Защищен транспорт: ModularCar (Owner: 76561198394504608)
[DisableVehicleDecay] Защищен транспорт: Minicopter (Owner: 76561198012345678)
```

## Технические детали

- Плагин отменяет vanilla decay методы для каждого типа транспорта
- Для ModularCar устанавливается `immuneToDecay = true`
- Новые транспортные средства автоматически защищаются через хуки `OnEntitySpawned`
- При выгрузке плагина decay восстанавливается для всех транспортных средств

## Примечания

- Плагин полностью отключает decay, транспортные средства не будут ломаться со временем
- Защита применяется автоматически при размещении новых транспортных средств
- При отключении плагина транспортные средства снова начнут ломаться (если не защищены другими плагинами)
- Плагин работает со всеми типами транспортных средств, поддерживаемых в Rust
