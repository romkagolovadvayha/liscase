# DisableTurrets

Плагин для отключения всех турелей, установленных игроками на сервере Rust.

## Описание

Плагин автоматически отключает все турели (AutoTurret), установленные игроками на сервере. Поддерживает автоматическое отключение при размещении турелей и периодическую проверку всех турелей на сервере.

## Возможности

- ✅ Автоматическое отключение всех турелей при загрузке плагина
- ✅ Автоматическое отключение турелей при их размещении игроками
- ✅ Периодическая проверка и отключение турелей (опционально)
- ✅ Логирование отключений
- ✅ Уведомления игроков при отключении их турелей (опционально)
- ✅ Команды для управления плагином
- ✅ Консольные команды для администраторов

## Установка

1. Скопируйте файл `DisableTurrets.cs` в папку `oxide/plugins/`
2. Плагин автоматически загрузится при следующей перезагрузке сервера или плагинов
3. Настройте конфигурацию в файле `oxide/config/DisableTurrets.json`

## Конфигурация

```json
{
  "Включить плагин": true,
  "Автоматически отключать турели при размещении": true,
  "Период проверки турелей (секунды, 0 = отключено)": 0.0,
  "Логировать отключение турелей": true,
  "Уведомлять игроков при отключении их турелей": false
}
```

### Параметры конфигурации

- **Включить плагин** - Включает/выключает плагин
- **Автоматически отключать турели при размещении** - Если включено, турели будут автоматически отключаться сразу после размещения игроком
- **Период проверки турелей** - Интервал в секундах для периодической проверки всех турелей на сервере. Установите 0 для отключения периодической проверки
- **Логировать отключение турелей** - Включает логирование в консоль сервера при отключении турелей
- **Уведомлять игроков при отключении их турелей** - Если включено, игроки будут получать сообщение в чат при отключении их турелей

## Команды

### Игровые команды (чат)

- `/disableturrets` - Показать справку по командам
- `/disableturrets all` - Отключить все турели на сервере
- `/disableturrets count` - Показать количество турелей (всего, включено, отключено)
- `/disableturrets enable` - Включить плагин
- `/disableturrets disable` - Выключить плагин
- `/disableturrets status` - Показать статус плагина и текущие настройки

### Консольные команды

- `disableturrets.all` - Отключить все турели на сервере
- `disableturrets.count` - Показать статистику по турелям
- `disableturrets.enable` - Включить плагин
- `disableturrets.disable` - Выключить плагин

## Права доступа

Для использования игровых команд требуется право: `disableturrets.admin`

Выдать право игроку:
```
oxide.grant <player> disableturrets.admin
```

Выдать право группе:
```
oxide.grant group <group> disableturrets.admin
```

## Примеры использования

### Базовое использование

1. Загрузите плагин - все существующие турели будут автоматически отключены
2. При размещении новых турелей они будут автоматически отключаться (если включено в конфиге)

### Периодическая проверка

Если вы хотите, чтобы плагин периодически проверял и отключал турели (например, каждые 60 секунд), установите в конфиге:

```json
"Период проверки турелей (секунды, 0 = отключено)": 60.0
```

### Ручное управление

Администратор может вручную отключить все турели командой:
```
/disableturrets all
```

Проверить количество турелей:
```
/disableturrets count
```

## Логирование

При включенном логировании в консоли сервера будут отображаться сообщения вида:

```
[DisableTurrets] Отключено турелей: 5
[DisableTurrets] Отключена турель. Владелец: PlayerName (ID: 76561198394504608)
```

## Примечания

- Плагин отключает турели, но не удаляет их. Игроки могут вручную включить турели обратно, но они будут снова отключены при следующей проверке (если включена)
- Турели отключаются через стандартный API Rust (`SetIsOnline(false)`)
- Плагин работает только с турелями типа `AutoTurret`
- При отключении плагина турели остаются в том состоянии, в котором были
