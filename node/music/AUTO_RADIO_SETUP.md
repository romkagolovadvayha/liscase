# Настройка автоматического подключения к радио

Эта функция позволяет боту автоматически подключаться к голосовому каналу и воспроизводить радио при запуске.

## Настройка через параметры командной строки (самый простой способ)

Вы можете передать ID канала и URL радио напрямую при запуске:

```bash
# Для первого бота
node main.js <channelId> <radioUrl>

# Для второго бота
node main2.js <channelId> <radioUrl>
```

### Примеры:

```bash
# Подключиться к каналу 1234567890123456789 и играть радио на порту 8081
node main.js 1234567890123456789 http://localhost:8081/stream

# Подключиться к каналу 9876543210987654321 и играть радио на порту 8082
node main2.js 9876543210987654321 http://localhost:8082/stream

# Использовать внешний URL
node main.js 1234567890123456789 http://radio.example.com:8081/stream
```

**Преимущества:**
- ✅ Не нужно редактировать файлы конфигурации
- ✅ Можно легко запускать разные боты с разными настройками
- ✅ Удобно для скриптов и автоматизации

## Настройка через переменные окружения

Создайте файл `.env` в папке `node/music` или добавьте переменные в существующий:

```env
# Включить автоматическое подключение к радио
AUTO_RADIO_ENABLED=true

# ID голосового канала Discord (можно получить, включив режим разработчика в Discord)
AUTO_RADIO_CHANNEL_ID=1234567890123456789

# URL радио потока
# Для первого бота (main.js):
AUTO_RADIO_URL=http://localhost:8081/stream

# Для второго бота (main2.js):
AUTO_RADIO_URL=http://localhost:8082/stream

# Или для третьего:
AUTO_RADIO_URL=http://localhost:8083/stream
```

## Настройка через config.js

Если вы не хотите использовать переменные окружения, можете изменить настройки напрямую в `config.js` или `config2.js`:

```javascript
autoRadio: {
    enabled: true, // Включить авто-подключение
    channelId: '1234567890123456789', // ID голосового канала
    radioUrl: 'http://localhost:8081/stream', // URL радио потока
    reconnectDelay: 5000, // Задержка перед переподключением (мс)
    autoReconnect: true // Автоматически переподключаться при отключении
}
```

## Как получить ID голосового канала

1. Включите режим разработчика в Discord:
   - Настройки → Расширенные → Режим разработчика
   
2. Правой кнопкой мыши на голосовой канал → Копировать ID

## Запуск

После настройки просто запустите бота:

```bash
# Для первого бота
node main.js

# Для второго бота
node main2.js
```

Бот автоматически подключится к указанному каналу и начнёт воспроизводить радио.

## Особенности

- ✅ Автоматическое подключение при запуске бота
- ✅ Автоматическое переподключение при отключении
- ✅ Бот не выходит из канала, даже если он пустой
- ✅ Радио продолжает играть постоянно
- ✅ Обработка ошибок с автоматическим переподключением

## Примеры URL для разных радиостанций

- Радио 1: `http://localhost:8081/stream`
- Радио 2: `http://localhost:8082/stream`
- Радио 3: `http://localhost:8083/stream`

Если радио работает на другом сервере, используйте полный URL:
- `http://your-server.com:8081/stream`
- `https://radio.example.com/stream`
