# Тест-кейсы для фронтенда

## 1. Аутентификация и авторизация

### 1.1. Steam OAuth
- [ ] **TC-AUTH-001**: Открытие страницы авторизации через Steam
  - Действие: Нажать на кнопку "Войти через Steam"
  - Ожидаемый результат: Редирект на Steam OAuth страницу
  
- [ ] **TC-AUTH-002**: Успешная авторизация через Steam
  - Действие: Завершить авторизацию в Steam
  - Ожидаемый результат: Редирект обратно на фронтенд, токены сохранены, пользователь авторизован
  
- [ ] **TC-AUTH-003**: Проверка сохранения токенов после авторизации
  - Действие: Проверить localStorage после авторизации
  - Ожидаемый результат: В localStorage есть access_token и refresh_token
  
- [ ] **TC-AUTH-004**: Автоматическое обновление токена при истечении
  - Действие: Дождаться истечения access token
  - Ожидаемый результат: Токен автоматически обновляется через refresh token
  
- [ ] **TC-AUTH-005**: Выход из системы
  - Действие: Нажать кнопку "Выйти"
  - Ожидаемый результат: Токены удалены, пользователь разлогинен, редирект на главную

### 1.2. Защищенные маршруты
- [ ] **TC-AUTH-006**: Доступ к защищенным страницам без авторизации
  - Действие: Попытаться открыть /profile, /support, /store и т.д. без авторизации
  - Ожидаемый результат: Редирект на страницу авторизации или показ модального окна
