# Чеклист проверки функциональности

## ✅ Проверено

### API Клиент
- ✅ JWT токены сохраняются в localStorage
- ✅ Токены автоматически добавляются к запросам
- ✅ Автоматическое обновление токена при 401
- ✅ Обработка ошибок (401, 403, 404, 500)
- ✅ Предотвращение множественных запросов на обновление токена

### Кэширование данных (React Query)
- ✅ useServersData - кэширование на 30 секунд, автообновление каждую минуту
- ✅ useProducts - infinite query с кэшированием
- ✅ useProductCategories - кэширование категорий
- ✅ useBlogPosts - кэширование постов блога
- ✅ useSettings - кэширование настроек
- ✅ Дублирование запросов предотвращается через React Query

### Авторизация
- ✅ Steam OAuth редирект на фронтенд после авторизации
- ✅ Сохранение токенов в localStorage после callback
- ✅ Проверка авторизации через isAuthenticated()
- ✅ Защита поддержки - показ модального окна для неавторизованных

## 🔍 Требует проверки

### Страницы без клиентских компонентов
- ⚠️ Некоторые страницы могут еще использовать server-side рендеринг
- ⚠️ Проверить все страницы на использование 'use client'

### Обработка ошибок
- ⚠️ Нет глобального Error Boundary
- ⚠️ Компоненты должны показывать понятные сообщения об ошибках

### Защита маршрутов
- ⚠️ Нет middleware для защиты маршрутов
- ⚠️ Каждая страница должна проверять авторизацию самостоятельно

### Производительность
- ⚠️ Проверить размер бандла
- ⚠️ Проверить lazy loading для компонентов

## 🐛 Известные проблемы

### Исправлено
- ✅ Дублирование API запросов (исправлено через React Query)
- ✅ Hydration ошибки (исправлено в ServersList)
- ✅ TypeError: servers.forEach (исправлено проверками массива)
- ✅ Рендеринг объекта категории в блоге (исправлено извлечением name)

### Требует внимания
- ⚠️ Некоторые компоненты могут не обрабатывать состояния загрузки
- ⚠️ Нет обработки offline режима
- ⚠️ Нет retry логики для failed запросов (только для refresh token)

## 📋 Рекомендации

### 1. Добавить Error Boundary
Создать глобальный Error Boundary для обработки ошибок React

### 2. Добавить middleware для защиты маршрутов
Использовать Next.js middleware для редиректа неавторизованных пользователей

### 3. Добавить retry логику
Настроить retry для failed запросов в React Query

### 4. Добавить offline поддержку
Обрабатывать состояние offline и показывать соответствующие сообщения

### 5. Оптимизировать бандл
Использовать dynamic imports для больших компонентов

### 6. Добавить аналитику ошибок
Интегрировать Sentry или аналогичный сервис для отслеживания ошибок
