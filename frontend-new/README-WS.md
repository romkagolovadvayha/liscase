# WebSocket Server

В приложении реализован WebSocket сервер для обновления баланса и других событий в реальном времени.

## Запуск

### Вариант 1: Отдельный процесс (рекомендуется)

Запустите WebSocket сервер в отдельном терминале:

```bash
npm run dev:ws
```

Или вместе с Next.js:

```bash
npm run dev:all
```

### Вариант 2: Интеграция в Next.js (в разработке)

WebSocket сервер можно интегрировать в Next.js через серверный файл, но это требует дополнительной настройки.

## Настройка

Создайте файл `.env.local` и добавьте:

```env
WS_PORT=4888
NEXT_PUBLIC_WS_URL=ws://localhost:4888
```

## Использование

WebSocket сервер автоматически отправляет обновления баланса после покупки товаров.

Клиенты подключаются с действием `auth` и передают `token` и `steam_id`:

```javascript
{
  "action": "auth",
  "token": "auth_token_from_cookie",
  "steam_id": "76561198012345678"
}
```

После успешной аутентификации сервер отправляет обновления баланса сообщениями типа:

```javascript
{
  "type": "update.balance",
  "code": 200,
  "balanceStr": "1 000",
  "balance": 1000,
  "hash": "random_hash"
}
```

## Порт

По умолчанию WebSocket сервер запускается на порту **4888**. Измените порт через переменную окружения `WS_PORT`.
