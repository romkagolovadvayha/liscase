# Настройка автоматического обновления виджета ВК через Cron

## Описание

После установки виджета данные сохраняются в базе данных. Для автоматического обновления данных виджета необходимо настроить cron-задачу, которая будет периодически обновлять все активные виджеты.

## Шаги настройки

### 1. Выполнить миграцию базы данных

Сначала нужно создать таблицу для хранения информации о виджетах:

```bash
php yii migrate
```

Миграция `m260101_120000_create_vk_widgets_table` создаст таблицу `vk_widgets` в базе данных.

### 2. Настроить cron-задачу

Добавьте следующую строку в crontab для обновления виджетов каждые 5 минут:

```bash
*/5 * * * * cd /path/to/project && php yii vk-widget/update-all >> /dev/null 2>&1
```

Или для обновления каждые 3 минуты:

```bash
*/3 * * * * cd /path/to/project && php yii vk-widget/update-all >> /dev/null 2>&1
```

### 3. Проверить работу

Вы можете вручную запустить команду для проверки:

```bash
php yii vk-widget/update-all
```

Эта команда обновит все активные виджеты, найденные в базе данных.

### 4. Обновить конкретный виджет

Если нужно обновить только один виджет:

```bash
php yii vk-widget/update 12345678
```

Где `12345678` - это ID сообщества ВК.

## Важные замечания

1. **Токен доступа**: Для автоматического обновления виджетов требуется токен пользователя с правами `app_widget`. Токен сохраняется в зашифрованном виде в базе данных при установке виджета.

2. **Срок действия токена**: Токены пользователя могут иметь ограниченный срок действия. Если токен истёк, автоматическое обновление не будет работать. В этом случае нужно переустановить виджет или обновить токен вручную.

3. **Логирование**: Все ошибки обновления логируются в файлы логов Yii2. Проверяйте логи, если виджеты не обновляются.

4. **Частота обновления**: Рекомендуется обновлять виджеты не чаще, чем раз в 3-5 минут, чтобы не перегружать API ВК.

## Структура таблицы vk_widgets

- `id` - ID записи
- `group_id` - ID сообщества ВК
- `app_id` - ID приложения ВК
- `logo_icon_id` - ID иконки логотипа (опционально)
- `api_url` - URL API для получения данных о серверах
- `access_token` - Зашифрованный токен доступа для обновления виджета
- `status` - Статус (0 - отключен, 1 - активен)
- `created_at` - Дата создания
- `updated_at` - Дата последнего обновления

## Пример cron-задачи для обновления каждые 5 минут

```bash
# Редактировать crontab
crontab -e

# Добавить строку (замените /path/to/project на реальный путь к проекту)
*/5 * * * * cd /var/www/html/liscase && php yii vk-widget/update-all >> /var/log/vk-widget-update.log 2>&1
```

## Устранение проблем

### Виджет не обновляется

1. Проверьте, что виджет активен в базе данных:
   ```sql
   SELECT * FROM vk_widgets WHERE status = 1;
   ```

2. Проверьте логи выполнения cron:
   ```bash
   tail -f /var/log/vk-widget-update.log
   ```

3. Попробуйте обновить вручную:
   ```bash
   php yii vk-widget/update-all
   ```

### Ошибка токена

Если в логах появляется ошибка о токене доступа, нужно:
1. Переустановить виджет через админ-панель
2. Или обновить токен в базе данных вручную
