# Инструкция по публикации VK Mini App

## Шаг 1: Сборка приложения

Соберите приложение для продакшена:

```bash
cd vk-apps
npm run build
```

После сборки файлы будут в папке `dist/`.

## Шаг 2: Загрузка на хостинг

Загрузите содержимое папки `dist/` на ваш хостинг. Например:

- **Путь на сервере**: `https://prostoj.store/vk-apps/`
- Или любой другой доступный URL

Убедитесь, что:
- Все файлы доступны по HTTPS
- Сервер правильно отдает статические файлы
- `index.html` доступен по корневому пути вашего приложения

## Шаг 3: Создание приложения в VK Developers

1. Перейдите на [VK Developers](https://dev.vk.com/)
2. Войдите в свой аккаунт ВКонтакте
3. Нажмите **"Создать приложение"**
4. Выберите тип: **"Мини-приложение"**
5. Заполните информацию:
   - **Название**: Мониторинг серверов
   - **Описание**: Мониторинг серверов в реальном времени
   - **Категория**: Игры или Другое

## Шаг 4: Настройка приложения

В настройках приложения:

1. **Основная информация**:
   - Загрузите иконку приложения (512x512px)
   - Загрузите изображение для каталога (1024x500px)

2. **Настройки мини-приложения**:
   - **URL приложения**: `https://prostoj.store/vk-apps/` (ваш URL)
   - **URL для разработки**: `http://localhost:10888` (для тестирования)
   - **Разрешения**: Обычно не требуются для этого приложения

3. **Настройки безопасности**:
   - Добавьте домен `prostoj.store` в список разрешенных доменов
   - Включите HTTPS (обязательно для продакшена)

## Шаг 5: Добавление в группу

1. Перейдите в настройки вашей группы ВКонтакте
2. Выберите **"Разделы"** → **"Приложения"**
3. Нажмите **"Добавить приложение"**
4. Найдите ваше приложение по названию или ID
5. Нажмите **"Добавить"**

## Шаг 6: Настройка в группе

После добавления приложения:

1. В настройках группы → **"Разделы"** → **"Приложения"**
2. Найдите ваше приложение и нажмите **"Настроить"**
3. Выберите, где отображать приложение:
   - В меню группы
   - В виджете на главной странице
   - В боковом меню

## Важные моменты

### Для разработки:
- Используйте `npm run dev` для локальной разработки
- В настройках приложения укажите `http://localhost:10888` как URL для разработки
- Используйте проксирование или ngrok для тестирования на мобильных устройствах

### Для продакшена:
- Обязательно используйте HTTPS
- Убедитесь, что CORS настроен правильно (уже настроено в API)
- Проверьте, что все файлы загружаются корректно

### Проверка работы:
1. Откройте вашу группу ВКонтакте
2. Перейдите в раздел с приложением
3. Приложение должно загрузиться и показать список серверов

## Структура файлов после сборки

После `npm run build` в папке `dist/` будут:
```
dist/
├── index.html
├── assets/
│   ├── index-[hash].js
│   ├── index-[hash].css
│   └── ...
```

Все эти файлы нужно загрузить на хостинг.

## Обновление приложения

После изменений:
1. Соберите приложение заново: `npm run build`
2. Загрузите обновленные файлы на хостинг
3. Очистите кеш браузера или подождите несколько минут
