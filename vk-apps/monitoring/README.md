# VK Мониторинг серверов

Проект содержит два варианта приложения для ВКонтакте:
1. **Плагин для сообществ** (`widget.html`) - плагин для встраивания на главную страницу сообщества
2. **Мини-приложение** (React) - полноценное приложение, открывается отдельно

## 🎯 Плагин для сообществ (рекомендуется)

Простой и легкий HTML-плагин для ВКонтакте с поддержкой VK Bridge. Создается в панели управления как **"Плагин для сообществ"**.

**Файл**: `widget.html`

### Особенности:
- ✅ Интеграция с VK Bridge
- ✅ Поддержка копирования через VK API
- ✅ Безопасное экранирование данных
- ✅ Адаптивный дизайн
- ✅ Автообновление каждые 30 секунд

### Быстрый старт:

1. Создайте плагин в [VK Developers](https://dev.vk.com/apps?act=manage) (тип: "Плагин для сообществ")
2. Загрузите `widget.html` на хостинг с HTTPS
3. Укажите URL в настройках плагина
4. Добавьте плагин в сообщество

📖 **Подробная инструкция**: [WIDGET_SETUP.md](WIDGET_SETUP.md)

## 📱 Мини-приложение

Мини-приложение для ВКонтакте, отображающее мониторинг серверов в реальном времени.

## Технологии

- React 18
- VKUI - библиотека компонентов ВКонтакте
- VK Bridge - для взаимодействия с платформой
- Vite - сборщик проекта

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:10888`

## Сборка

```bash
npm run build
```

Собранные файлы будут в папке `dist/`:
- `index.html` - мини-приложение (React)
- `widget.html` - плагин для сообществ (автоматически копируется при сборке)
- `assets/` - ресурсы приложения
- Файлы из папки `public/`

## Настройка в ВКонтакте

1. Перейдите в [Управление приложениями](https://vk.com/apps?act=manage)
2. Создайте новое мини-приложение
3. Укажите URL вашего приложения (например: `https://yourdomain.com/vk-apps/`)
4. Для разработки используйте адрес `http://localhost:10888` с настройкой проксирования
5. Сохраните настройки

## API

Приложение использует API для получения данных о серверах. URL API можно настроить через параметры URL.

### Настройка API URL через параметры

Вы можете передать адрес API через параметры URL в трех вариантах:

1. **Полный URL API** (приоритет):
   ```
   ?api_url=https://api.example.com/servers
   ```

2. **Базовый URL сайта** (рекомендуется):
   ```
   ?api_base_url=https://api.example.com
   ```
   Или через параметр `site_url`:
   ```
   ?site_url=https://api.example.com
   ```
   В этом случае автоматически будет построен URL: `https://api.example.com/servers`

3. **Значение по умолчанию** (если параметры не указаны):
   ```
   https://api.prostoj.store/servers
   ```

### Примеры URL с параметрами:

```
https://monitoring-apps.prostoj.store/widget.html?api_base_url=https://api.example.com&vk_app_id=123456
```

```
https://monitoring-apps.prostoj.store/widget.html?api_url=https://api.example.com/servers&vk_app_id=123456
```

### Формат ответа API

```json
[
  {
    "name": "ПРОСТОЙ #1 [MAX3]",
    "ip": "195.18.27.169",
    "port": 35100,
    "query": 35110,
    "tag": "max3",
    "online": 27,
    "joined": 0,
    "max": 200,
    "tags": "biweekly, oxide, russian, skins"
  }
]
```
