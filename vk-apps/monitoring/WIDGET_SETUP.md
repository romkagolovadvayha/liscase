# Установка плагина (виджета) в сообщество ВКонтакте

## Что такое плагин для сообществ?

Плагин для сообществ — это специальный тип мини-приложения ВКонтакте, который можно добавить в сообщество и запускать прямо со страницы сообщества. Плагины создаются и настраиваются в панели управления как мини-приложения типа **"Плагин для сообществ"**.

## Файл плагина

Плагин находится в файле `widget.html` — это самодостаточная HTML-страница с поддержкой VK Bridge, готовая к использованию как плагин для сообществ.

## Шаг 1: Сборка и загрузка плагина на хостинг

### Сборка проекта:

```bash
npm run build
```

После сборки файл `widget.html` автоматически будет скопирован в папку `dist/` вместе с остальными файлами приложения.

### Загрузка на хостинг:

1. Загрузите содержимое папки `dist/` на ваш хостинг (включая `widget.html`)
2. Убедитесь, что файл доступен по **HTTPS** (обязательно!)
3. Запомните URL, например: `https://prostoj.store/vk-apps/monitoring/dist/widget.html`

## Шаг 2: Создание плагина в VK Developers

1. Перейдите в [панель управления приложениями](https://vk.com/apps?act=manage)
2. Нажмите **"Создать приложение"**
3. Выберите тип: **"Плагин для сообществ"**
4. Укажите название: **"Мониторинг серверов"**
5. Выберите категорию (например: **"Игры"** или **"Другое"**)
6. Нажмите **"Создать"** и подтвердите создание плагина

## Шаг 3: Настройка плагина

В настройках созданного плагина:

### Основная информация:
1. **URL приложения**: Укажите URL вашего плагина
   - Для продакшена: `https://prostoj.store/vk-apps/monitoring/widget.html`
   - Для разработки: `http://localhost:10888` (с проксированием)
2. Загрузите иконку приложения (512x512px)
3. Загрузите изображение для каталога (1024x500px)
4. Заполните описание плагина

### Важные настройки:
1. **Запуск приложения из сообщества**: ✅ Включите эту опцию
2. **Официальное сообщество**: Выберите ваше сообщество (для непроверенных плагинов)
3. Добавьте домен в список разрешенных (например: `prostoj.store`)

## Шаг 4: Добавление плагина в сообщество

### Автоматическое добавление (рекомендуется)

После добавления плагина в сообщество через раздел **"Приложения"**:

1. Перейдите в ваше сообщество ВКонтакте
2. Откройте раздел с плагином
3. Откроется **админ-панель** плагина с кнопкой **"Добавить виджет на главную страницу"**
4. Нажмите кнопку для добавления виджета
5. Виджет будет автоматически добавлен на главную страницу сообщества

### Ручное добавление через настройки сообщества

Если автоматическое добавление не работает:

1. Перейдите в настройки вашего сообщества
2. Откройте **"Управление"** → **"Разделы"** → **"Виджеты"**
3. Нажмите **"Добавить виджет"** → **"Встраиваемый виджет"**
4. Вставьте URL виджета: `https://ваш-домен.com/vk-apps/monitoring/dist/widget.html?widget=1`
5. Сохраните настройки

## Шаг 5: Настройка параметров (опционально)

Вы можете передать параметры через URL для настройки API и других параметров.

### Параметры API URL:

Адрес API можно передать тремя способами:

1. **Полный URL API** (приоритет):
   ```
   ?api_url=https://api.example.com/servers
   ```

2. **Базовый URL сайта** (рекомендуется):
   ```
   ?api_base_url=https://api.example.com
   ```
   Или через параметр `site_url`:
   ```
   ?site_url=https://api.example.com
   ```
   В этом случае автоматически будет построен URL: `https://api.example.com/servers`

3. **Значение по умолчанию** (если параметры не указаны):
   ```
   https://api.prostoj.store/servers
   ```

### Другие параметры:

- `logo_url` — URL логотипа сервера (по умолчанию: `/server_logo.png`)

### Примеры полных URL:

```
https://prostoj.store/vk-apps/monitoring/widget.html?api_base_url=https://api.example.com&logo_url=https://your-site.com/logo.png
```

```
https://prostoj.store/vk-apps/monitoring/widget.html?api_url=https://api.example.com/servers
```

## Модерация плагина

После создания плагин имеет статус **непроверенного приложения**. Чтобы пройти проверку:

### Подготовка к модерации:

1. ✅ Убедитесь, что плагин соответствует [Правилам размещения мини-приложений](https://dev.vk.com/mini-apps/rules)
2. ✅ Заполните все обязательные поля в настройках:
   - Название и описание плагина
   - Иконки и скриншоты
   - Политика конфиденциальности (ссылка)
3. ✅ Включите плагин для пользователей
4. ✅ Протестируйте на всех платформах (Mobile, Web, iOS, Android)

### Отправка заявки на модерацию:

1. В настройках плагина перейдите в раздел **"Модерация"**
2. Нажмите **"Отправить заявку"**
3. Выберите платформы для проверки:
   - Web
   - iOS (требуется Apple Developer ID)
   - Android
4. Опишите идею и задачи плагина, целевую аудиторию
5. Нажмите **"Отправить заявку"**

### Преимущества после модерации:

- ✅ Нет предупреждающего экрана о непроверенном приложении
- ✅ Отображается сниппет при размещении ссылки
- ✅ Можно подключать платежи и рекламу
- ✅ На iOS открывается в WebView (прямо в ВКонтакте)
- ✅ Плагин размещается в каталоге плагинов
- ✅ Можно продвигать через сообщество и рекламу

## Проверка работы

1. Откройте главную страницу вашего сообщества
2. Виджет должен отображаться автоматически
3. Проверьте, что данные загружаются корректно
4. Проверьте работу на мобильных устройствах

## Особенности плагина

- ✅ **Легкий и быстрый** — чистый HTML/CSS/JS без тяжелых фреймворков
- ✅ **VK Bridge** — интеграция с платформой ВКонтакте
- ✅ **Адаптивный** — автоматически подстраивается под размер контейнера
- ✅ **Автообновление** — обновляет данные каждые 30 секунд
- ✅ **Интерактивный** — клик по серверу копирует команду подключения
- ✅ **Кроссплатформенный** — работает на Web, iOS, Android

## Обновление плагина

После изменения `widget.html`:

1. Загрузите обновленный файл на хостинг
2. Изменения применятся автоматически (может потребоваться очистка кеша)
3. Если плагин прошел модерацию, изменения вступят в силу сразу

## Решение проблем

### Плагин не отображается в сообществе
- ✅ Проверьте, что файл доступен по **HTTPS** (обязательно!)
- ✅ Проверьте, что в настройках плагина включена опция **"Запуск приложения из сообщества"**
- ✅ Убедитесь, что плагин добавлен в сообщество через раздел "Приложения"
- ✅ Проверьте, что домен добавлен в список разрешенных доменов
- ✅ Для непроверенных плагинов: выберите официальное сообщество в настройках

### Данные не загружаются
- ✅ Проверьте консоль браузера на наличие ошибок
- ✅ Убедитесь, что API доступен и возвращает данные
- ✅ Проверьте CORS настройки API сервера
- ✅ Проверьте параметр `api_url` в URL плагина

### Плагин выглядит неправильно
- ✅ Проверьте, что CSS загружается корректно
- ✅ Убедитесь, что нет конфликтов стилей с VK
- ✅ Проверьте работу на мобильных устройствах (iOS, Android)

### VK Bridge не работает
- ✅ Плагин автоматически определяет наличие VK Bridge
- ✅ Вне ВКонтакте используется fallback функциональность
- ✅ Проверьте, что скрипт VK Bridge загружается корректно
