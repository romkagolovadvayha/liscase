# VK Mini App - Мониторинг серверов

Мини-приложение для ВКонтакте, отображающее мониторинг серверов в реальном времени.

## Возможности

- 📊 Отображение списка всех серверов
- 🔄 Автоматическое обновление каждые 30 секунд
- 📱 Адаптивный дизайн для мобильных устройств
- 🎨 Современный и красивый интерфейс
- ⚡ Быстрая загрузка данных
- 🏷️ Отображение тегов серверов

## Установка

1. Загрузите все файлы в каталог `vk-apps/`
2. Настройте хостинг для статических файлов
3. В настройках приложения ВКонтакте укажите URL вашего приложения

## Настройка в ВКонтакте

1. Перейдите в [Управление приложениями](https://vk.com/apps?act=manage)
2. Создайте новое мини-приложение
3. Укажите URL вашего приложения (например: `https://yourdomain.com/vk-apps/`)
4. Настройте права доступа (если необходимо)
5. Сохраните настройки

## API

Приложение использует API: `GET https://api.prostoj.store/servers`

### Формат ответа API

```json
[
  {
    "name": "ПРОСТОЙ #1 [MAX3]",
    "ip": "195.18.27.169",
    "port": 35100,
    "query": 35110,
    "tag": "max3",
    "online": 27,
    "joined": 0,
    "max": 200,
    "tags": "biweekly, oxide, russian, skins"
  }
]
```

## Особенности

- **Автообновление**: Данные обновляются каждые 30 секунд
- **Индикатор загрузки**: Показывается во время загрузки данных
- **Обработка ошибок**: Отображается сообщение об ошибке при проблемах с загрузкой
- **Визуализация заполненности**: Прогресс-бар показывает заполненность сервера
- **Цветовая индикация**: Разные цвета для разных уровней заполненности

## Кастомизация

Вы можете изменить:
- Интервал обновления в `app.js` (по умолчанию 30000 мс)
- Цвета и стили в `style.css`
- Структуру отображения в `app.js` (функция `createServerCard`)

## Поддержка

При возникновении проблем проверьте:
1. Доступность API `https://api.prostoj.store/servers`
2. Настройки CORS на сервере
3. Консоль браузера на наличие ошибок
